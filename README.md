# From User Feedback to Product Decisions

Comparing traditional (word-based) and semantic (transformer-based) NLP methods for discovering recurring product issues in user reviews of project management software (Trello).

**Data Science Senior Seminar — research project (in progress)**

## Contents
- `collect_reviews.py` — collects Google Play reviews and saves them to CSV
- `trello_reviews_raw.csv` — raw collected review dataset

## Data
Reviews collected from the Google Play Store using the `google-play-scraper`
library. Fields include review text, star rating, date, helpful-vote count, app version, and developer reply.
